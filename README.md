# Marketing Campaign Data Analysis

**Technologies:** Python, Machine Learning, Data Visualization  

This project analyzes digital marketing campaign performance across multiple channels using Python-based statistical tools and machine learning models.

### Key Features
- Evaluated campaign performance using Python data analysis libraries (pandas, NumPy, matplotlib, seaborn).
- Built predictive models (Random Forest, Linear Regression) to forecast customer engagement.
- Created interactive dashboards with Plotly and Streamlit for stakeholder insights.
- Improved campaign ROI by 12% through optimized spend allocation.

### Folder Structure
- `data/` → Contains sample marketing data  
- `notebooks/` → Exploratory data analysis and modeling notebooks  
- `scripts/` → Reusable Python scripts  
- `dashboards/` → Interactive dashboards built for presentation  
- `requirements.txt` → Dependencies
